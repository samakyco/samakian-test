# samakian-test

**Find Your House** — Samaky's beta volunteer personality quiz.

Nine questions based on the Volunteer Functions Inventory (Clary et al., 1998) place a student in one of four Houses (Karunos, Metthos, Bodhios, Pragnos) and one of eight personality types, then suggest volunteer roles and help them make a plan to go.

The whole site is one file, `index.html`, published with GitHub Pages.

Volunteer opportunities shown on the results page are sample data.
